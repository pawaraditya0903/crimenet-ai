## 🧮 3. Algorithmic Engine & Mathematical Formulations

1. **Isolation Forest Ensemble (Anomaly Detection):**
   $$s(x, n) = 2^{-\frac{E(h(x))}{c(n)}}$$
   Identifies suspicious banking outliers (e.g. ₹1.5 Cr midnight transfers) in shorter tree depths.
2. **Benford's Law Chi-Square ($\chi^2$) Goodness-of-Fit:**
   $$P(d) = \log_{10}\left(1 + \frac{1}{d}\right),\quad \chi^2 = \sum_{d=1}^9 \frac{(O_d - E_d)^2}{E_d}$$
   Tests digit distribution of transaction logs to expose fabricated financial bookkeeping ($p < 0.001$).
3. **Johnson's Elementary Cycle Algorithm:**
   Finds all elementary directed cycles in $O((V+E)(C+1))$ time to expose circular money-laundering loops (`CYCLE-01`).
4. **PageRank & Betweenness Centrality:**
   Calculates topological eigenvector authority to unmask the true syndicate Kingpin hiding behind mule accounts.
5. **Louvain Modularity Optimization:**
   Partitions the graph into distinct functional crime units (Hawala Cell, Logistics Cell, Command Cell).
6. **Ford-Fulkerson Max Flow & Structuring:**
   Computes transaction throughput and identifies smurfing strategies kept beneath the ₹50,000 PAN threshold.
7. **Weighted Least Squares (WLS) Radio Trilateration:**
   Calculates exact target coordinates from 3 cell towers with Geometric Dilution of Precision ($\text{GDOP} = 1.14$, $\pm 12.4\text{m}$ precision).
8. **Kalman Filter (2D Covariance State Prediction):**
   Projects dynamic target vehicle trajectories and calculates tactical intercept points with ETA.
9. **Zero-Mean Normalized Cross-Correlation (ZNCC):**
   Provides spoof-resistant facial biometric authentication with $\ge 82.0\%$ correlation threshold.

    Maintains cryptographic chain of custody for all evidence files, ensuring 100% tamper-evident audit trails.
