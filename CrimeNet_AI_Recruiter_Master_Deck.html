Mathematical Kingpin Discovery: PageRank & Centrality

PageRank Algorithm (Global Authority)

PageRank models the structural authority of each suspect across the entire syndicate graph. It calculates iterative eigenvector probability: A node with few high-authority links outranks nodes with many low-level contacts.

PR(u) = (1-d)/N + d * Σ (PR(v) / L(v)) | d = 0.85

Outcome: Exposes Kingpin Arjun Mehta (PR: 0.0847, Rank #1) despite maintaining only 2 direct contacts.

Betweenness Centrality (Bridge / Broker Discovery)

Measures how often a node acts as a bridge along the shortest geodesic path between other entities.

g(v) = Σ (σ_st(v) / σ_st) across all pairs (s,t)

Tactical Arrest: Neutralizing bridge node Vikram Singh (g=0.312) cuts communication between hawala and logistics.
